# 自動建立的工作表格式

`templet` 現在只是歷史名詞，**不是學生安裝所需的檔案或頁籤**。
`sheetSchema.js` 在建立新管理頁時產生欄位、顏色、欄寬及控制值，不會覆蓋既有頁面的格式或紀錄。

## 身分與名稱分離

LINE 對話 ID → Script Properties registry → 固定 sheetId 與 folderId。
頁籤名稱及 A3 是可讀標籤；A4 是 Drive folderId，不是群組 ID。
同名群組會加序號，不會共用資料夾。改名、換頁籤順序不改 LINE 收件者。

初始化安裝擁有者的可安裝觸發器，支援 A3／頁籤手動改名同步到 Drive。
Drive 資料夾單獨在 Drive 改名不會反向即時更新試算表；請從 A3、頁籤或 bot 的取名指令管理名稱。

## 控制區

| 位置 | 用途 |
| --- | --- |
| A2 | 該對話的初始主持人 ID |
| A3 | 可讀名稱 |
| A4 | 群組專屬 Drive 子資料夾 ID，不可手改 |
| A5 | 0 即時轉訊，-1 暫停，正值為既有定時設定 |
| A6 | 實際內容筆數，不包含新指令／搜尋操作 |
| A7、A8 | 保留舊欄位，新廣播狀態另存在 properties |
| B2 | 定時觸發器 ID |
| C、D | 成員 ID 與暱稱 |

第 1 列是欄位標題；C2 起是成員，不要拿 B2 放說明文字。
新群組 A5=0；管理員與操作中心頁 A5=-1，避免自我通知。
其他未登記頁（例如「工作表1」）會略過，無須刪除。

## 第 9 列起的內容紀錄

| 欄 | 用途 |
| --- | --- |
| E | 轉訊狀態：0 未即時轉訊、1 已處理、2 失敗 |
| F、G | 發話者 ID、暱稱 |
| H | 既有時間欄位，沿用歷史顯示方式 |
| I、J | 類型與內容／檔名 |
| K | 已保存的 Drive fileId；貼圖／位置為原始訊息資料 |
| L | MessageId，用來避免同一訊息重複新增 |
| M | 處理中／已記錄／已備份／備份失敗 |
| N | 原始事件，包含未加工的 timestamp 與 message |

歷史 H 欄有本地時間轉換後加 Z 的相容格式，不能直接當 UTC 分析；需要精確時刻時使用 N 的原始 timestamp。
備份失敗仍保留紀錄，不會宣稱已保存。搜尋／寫入根據實際內容列，不受較長的成員清單影響。
指令不新增內容列，但啟用轉訊時仍可產生管理提醒。未知的 // 文字不是已識別指令，仍作一般文字保存。

## 複本與遷移

不要將老師的試算表或 Script Properties 複製為學生設定。registry 有試算表 ID 命名空間，不會從同名標籤猜另一份表的資料。
已改名卻遺失 registry 的舊資料需人工核對；本 repo 沒有老師正式環境的遷移清單。
