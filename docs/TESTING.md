# 發布驗證與學生驗收

## 已自動測試

本機 npm test 與 GitHub Actions 使用隔離模擬服務，覆蓋：

- 空白綁定／獨立 Apps Script 的初始化、資源建立及重跑不破壞資料。
- 缺少設定、無效 token、錯誤管理員格式、複本 ID 衝突。
- 缺少／錯誤 webhook key 不寫資料，未初始化不接受事件。
- 新群組程式產生版型，不需 templet；同名群組各自獨立。
- A3／頁籤改名、名稱衝突、ID／資料夾一致性、改名後新增搜尋。
- 指令與內容分離、上傳失敗保留、重送去重、長成員清單。
- 廣播成功狀態、錯誤說明、貼圖去除來源 quoteToken。
- 管理員及其他成員的即時轉訊、附件來源卡片、暫停設定。
- 私人媒體保持私人，以權限連結代替無法由 LINE 讀取的圖片；公開音訊時長是數字。
- 原始碼中不得出現固定 LINE 身分／正式部署、硬寫 token 或已停用 Notify 呼叫。

這些測試**不是學生帳號的真實部署測試**，不能保證任何學校帳號政策、LINE 額度或外部服務狀態。

## 每位學生部署後必做

部署網址測試必須使用未登入 Google 的無痕視窗：完整 `/exec?key=...` 應顯示 `LearningBot webhook is reachable.`。若出現登入頁或 HTTP 401，先修正網頁應用程式的「執行身分：我／誰可以存取：所有人」，再進行 LINE Verify。

| 測試 | 成功條件 |
| --- | --- |
| initializeBot | ready:true；表與根資料夾都在自己的帳號；不需要老師的檔案 |
| 再跑一次初始化 | 沒有新增第二份相同資源、沒有清空資料 |
| 私訊「備份」 | 看見選單 |
| 新群組第一則普通文字 | 新頁＋子資料夾；第 9 列開始紀錄；管理員收到來源卡片 |
| 管理員本人在群組發話 | 也收到提醒；與 bot 的私聊不自我轉送 |
| //我是測試者、//取名測試甲 | 功能執行；A6 不因指令增加；名称一致 |
| 再建立測試乙 | 兩群的內容及資料夾不混用 |
| 手動改 A3，再改頁籤 | 名稱同步；sheetId、A4、舊列不變 |
| 改名後新增與搜尋 | 新訊息仍寫原頁；舊新資料可搜尋；不新增重複頁 |
| 圖片／PDF | 表中已備份；Drive 實際有檔；私人連結由獲授權帳號可開啟 |
| 文字＋支援貼圖＋圖片廣播 | 目標正確；私人圖片為連結；成功顯示完成；不能重複按同一確認 |
| 暫停轉訊 | 仍備份，但不再即時 push；恢復即時後才通知 |
| 定時功能 | 確認安裝帳號的觸發器及通知目標符合設定 |
| 更新版本 | 更新既有部署，原 URL/key 保留；再次執行上述基本測試 |

請使用很少量的假資料測試，Push 会使用 LINE 額度。不要自動重送送達結果未知的廣播。

## 範圍與已知限制

- H 欄沿用歷史時間顯示；精確時刻用 N 的原始事件 timestamp。
- 私人 Drive 檔案不保證在 LINE 内直接顯示；這不代表備份失敗。
- LINE 付費／創作者貼圖不一定支援 bot 發送。
- Webhook key 不是 HMAC 簽章；敏感資料不得直接使用本沙盒。
- 已改名且遺失 registry 的舊表不會自動猜測對應。
- 初始化失敗可修正設定後重跑；遇到已有資料的對應衝突應停下核對，不要刪頁重試。
